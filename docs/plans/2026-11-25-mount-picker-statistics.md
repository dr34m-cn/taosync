# 挂载目录选择与匿名统计实施计划

1. 复用作业的目录选择与新建交互。草稿挂载的目录操作校验引擎、驱动与凭据目标，阿里云盘保留按目录 ID 操作与令牌轮换，加密目录使用已选挂载且不解锁既有配置。
2. 系统设置合并两种 API 秘钥的说明，保留独立的密钥控制。在同步设置中新增默认开启、可持久化的匿名上报开关与双语隐私说明。
3. 任务结束只取本次成功复制、移动的文件数与逻辑字节数；不读取历史，不发送标识，不重试不确定是否送达的请求。
4. apiServer 公开两个计数字段的读写接口。单服务进程在内存中累加，启动时恢复，按分钟在后台写入一致快照；授信页独立刷新统计，不影响清单。
5. 验证目录校验、密钥复用边界、任务计数、开关与并发聚合、失败恢复；运行两套后端测试与乱序测试、apiServer 测试及前端构建。
