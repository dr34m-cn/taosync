## 🚀 特性

* 新增内置 TaoSync 引擎，支持本地目录、SMB、FTP、SFTP 和阿里云盘，无需部署 OpenList/AList [#124](https://github.com/dr34m-cn/taosync/issues/124) [#195](https://github.com/dr34m-cn/taosync/issues/195)
  * 支持浏览本地目录及跨磁盘同步 [#101](https://github.com/dr34m-cn/taosync/issues/101) [#143](https://github.com/dr34m-cn/taosync/issues/143)
  * 支持 SMB 设备发现、共享目录选择及并发扫描和传输，以及 SFTP 密钥认证
  * 阿里云盘支持扫码授权、目录选择、哈希秒传和云端重命名/移动；小于 100 MiB 的文件直接上传，较大文件尝试秒传，进度在云端提交和重名清理完成后才显示 100%
  * 复用扫描结果与文件信息，减少重复目录查询和缓存落盘，支持传输重试并提供慢请求日志
  * 内置存储支持源目标位置冲突检查；修改连接地址或账号等凭据关联信息后，需重新提供相应凭据
* 新增源目录模式：通过源目录快照减少目标端扫描；存储提供的哈希、修改时间等元数据发生变化时，可识别同大小文件的更新，不提供手动选择 MD5 等比对算法的选项 [#185](https://github.com/dr34m-cn/taosync/issues/185) [#198](https://github.com/dr34m-cn/taosync/issues/198)
  * 每个文件在所有目标同步完成后保存进度；中止或重启后可复用已完成且未变化的文件，失败文件继续重试，移动模式恢复时先校验目标再安全删除源文件
  * 首次运行完整比对目标目录，此后默认每 15 天完整比对，可通过 `source_full_scan_days` 或 `TAO_SOURCE_FULL_SCAN_DAYS` 调整，0 表示关闭定期比对；全同步完整比对时仍会按排除和过滤规则清理目标端多余内容
  * 仅新增配合源目录模式，完成首次同步并关闭定期完整比对后，源文件未变化时，目标端手动删除的已同步文件不会反复补传；源文件后续发生变化仍会重新同步 [#125](https://github.com/dr34m-cn/taosync/issues/125) [#199](https://github.com/dr34m-cn/taosync/issues/199) [#201](https://github.com/dr34m-cn/taosync/issues/201)
* 桌面端作业列表新增批量启用/禁用、展开/折叠；桌面端与移动端均展示上次执行结果摘要 [#227](https://github.com/dr34m-cn/taosync/issues/227)
* 移动模式自动清理本次移空的源子目录，保留源根目录及含排除、过滤或失败文件的目录 [#215](https://github.com/dr34m-cn/taosync/issues/215) [#157](https://github.com/dr34m-cn/taosync/issues/157)
* 新增并行复制数设置：TaoSync 按目标存储目录、OpenList/AList 按引擎共享额度，默认 5，支持 1～100
* 系统设置支持在线修改任务记录保留时间、任务超时、完整比对周期和阿里云盘授权服务地址，保存后即时生效
* 支持在用户菜单中修改用户名 [#155](https://github.com/dr34m-cn/taosync/issues/155)
* 新增高级自定义通知，支持请求头、请求体和 `$title`、`$content` 变量 [#107](https://github.com/dr34m-cn/taosync/issues/107)
* 新增 Bark 通知渠道 [#205](https://github.com/dr34m-cn/taosync/issues/205)，以及 pushPlus 和 PushDeer 通知
* 阿里云盘授权默认使用公共服务，也支持自建；支持并发处理扫码授权请求，新增独立 Docker 镜像 `dr34m/tao-sync:api-server`

## 🎨 优化

* 共用作业调度器并增加数据库索引，降低资源占用，加快历史记录查询
* 加强登录安全：密码改用 PBKDF2 加盐存储，改进会话保护，按来源 IP 限制密码错误次数。**升级后需重新登录，登录过新版本后不支持降级**
* 全同步增加空源保护：源目录为空而目标仍有内容时跳过并记为失败，避免挂载掉线后误清空目标。**如需清空目标，请手动处理**
* 运行中的作业禁止编辑，包括禁用后仍在收尾的作业
* 完善作业详情统计、目录自动创建与失败状态提示；平均速度使用精确同步时长计算，并排除传输前的纯扫描时间
* 优化构建缓存和多平台发布流程
