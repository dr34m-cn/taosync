## 🚀 特性

* 新增内置 TaoSync 引擎，支持本地目录、SMB、FTP、SFTP 和阿里云盘，无需部署 OpenList/AList [#124](https://github.com/dr34m-cn/taosync/issues/124) [#195](https://github.com/dr34m-cn/taosync/issues/195)
  * 支持浏览本地目录及跨磁盘同步 [#101](https://github.com/dr34m-cn/taosync/issues/101) [#143](https://github.com/dr34m-cn/taosync/issues/143)
  * 支持 SMB 设备发现、SFTP 密钥认证，以及阿里云盘扫码授权、目录选择、哈希秒传和云端重命名/移动
* 新增源目录模式：通过源目录快照减少目标端扫描，利用文件指纹识别同大小文件的变化；同步失败时保留原快照 [#185](https://github.com/dr34m-cn/taosync/issues/185) [#198](https://github.com/dr34m-cn/taosync/issues/198)
  * 默认每 15 天完整比对目标目录，可通过 `source_full_scan_days` 调整，0 表示关闭；全同步完整比对时仍会删除目标端多余文件
  * 仅新增配合源目录模式，并关闭定期完整比对后，目标端手动删除的已同步文件不会反复补传 [#125](https://github.com/dr34m-cn/taosync/issues/125) [#199](https://github.com/dr34m-cn/taosync/issues/199) [#201](https://github.com/dr34m-cn/taosync/issues/201)
* 作业列表新增批量启用/禁用、展开/折叠，以及上次执行结果摘要 [#227](https://github.com/dr34m-cn/taosync/issues/227)
* 移动模式自动清理本次移空的源子目录，保留源根目录及含排除、过滤或失败文件的目录 [#215](https://github.com/dr34m-cn/taosync/issues/215) [#157](https://github.com/dr34m-cn/taosync/issues/157)
* 新增并行复制数设置：TaoSync 按目标存储目录、OpenList/AList 按引擎共享额度，默认 5，支持 1～100
* 系统设置支持在线修改任务记录保留时间、任务超时、完整比对周期和阿里云盘授权服务地址，保存后即时生效
* 支持在用户菜单中修改用户名 [#155](https://github.com/dr34m-cn/taosync/issues/155)
* 新增高级自定义通知，支持请求头、请求体和 `$title`、`$content` 变量 [#107](https://github.com/dr34m-cn/taosync/issues/107)
* 新增 Bark、pushPlus 和 PushDeer 通知 [#205](https://github.com/dr34m-cn/taosync/issues/205)
* 阿里云盘授权默认使用公共服务，也支持自建；新增独立 Docker 镜像 `dr34m/tao-sync:api-server`

## 🎨 优化

* 完善移动安全校验：所有目标复制成功、文件大小一致且源文件未变化后才删除源文件；单个失败不影响其他文件 [#234](https://github.com/dr34m-cn/taosync/issues/234) [#175](https://github.com/dr34m-cn/taosync/issues/175) [#242](https://github.com/dr34m-cn/taosync/issues/242)
* 中止作业时等待传输取消并完整记录结果，避免残留操作与下次执行重叠 [#192](https://github.com/dr34m-cn/taosync/issues/192)
* 优化内置引擎与阿里云盘上传性能，减少缓存落盘和重复读取，改进传输进度、重试及错误提示
* 共用作业调度器并增加数据库索引，降低资源占用，加快历史记录查询
* 加强登录安全：密码改用 PBKDF2 加盐存储，改进会话保护，按来源 IP 限制密码错误次数。**升级后需重新登录，登录过新版本后不支持降级**
* 全同步增加空源保护：源目录为空而目标仍有内容时跳过并记为失败，避免挂载掉线后误清空目标。**如需清空目标，请手动处理**
* 阻止源、目标指向同一存储位置；运行中的作业禁止编辑，修改存储连接信息后需重新验证凭据
* 完善作业详情统计、目录自动创建与失败状态提示，优化构建缓存和多平台发布流程
