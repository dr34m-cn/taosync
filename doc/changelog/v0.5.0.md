## 🚀 特性

* 新增内置 TaoSync 存储引擎：无需部署 OpenList/AList 即可直接同步，引擎不可删除，可在引擎管理中新增、编辑和删除存储目录；作业可选择 TaoSync 引擎及其存储目录作为源目录和目标目录
* TaoSync 引擎支持本地目录、SMB、FTP、SFTP 和阿里云盘存储驱动，统一支持目录扫描、创建目录、复制、移动、删除、上传和下载
  * 本地目录支持浏览并选择服务器文件夹
  * SMB 支持扫描同网段设备选择主机，填写主机和端口后可枚举并选择共享名称，也可手动输入
  * SFTP 支持密码与私钥认证、私钥密码、连接测试与自动获取主机指纹，根目录支持手动输入或懒加载目录树选择，并做根目录隔离，拒绝路径穿越和符号链接逃逸
  * 阿里云盘支持扫码授权（通过独立部署的公共授权服务，通过 `data/config.ini` 的 `aliyun_auth_server` 或环境变量 `TAO_ALIYUN_AUTH_SERVER` 配置），也支持自行填写 `client_id`、`client_secret` 和 `refresh_token` 的直连模式
  * 复制完成后即时确认结果，无需等待状态轮询，大量小文件同步更快
* 新增源目录模式：首次同步仍完整比对目标目录，之后仅扫描源目录并与数据库中的快照比较生成同步操作，大幅减少对目标存储的扫描；通过文件指纹识别大小相同但内容已变化的文件，同步失败或扫描不完整时保留原快照
  * 按 `source_full_scan_hours`（环境变量 `TAO_SOURCE_FULL_SCAN_HOURS`，单位小时，默认 24，0 表示从不）定期完整比对一次目标目录，修复目标端被手动删除或修改的内容；全同步时，完整比对与普通全同步一样会删除目标端多出的文件
  * 全同步下，源端删除的目录在目标端为空时一并清理；目录内仍有用户自行添加或被排除的文件时保留
* 新增存储路径身份判断，阻止源目录和目标目录指向同一物理存储位置
* PC 端作业列表新增全部禁用/启用、全部折叠/展开按钮；PC 端展开区与移动端卡片展示上次执行的状态、时间、耗时、成功数/总数及成功率

## 🎨 优化

* 完善移动模式：多目标时全部复制成功后才删除源文件，删除前复查源文件是否变化
* 全同步的源目录模式下，目录变成同名文件时，会先清理快照中记录过的空目录再复制文件；目录中存在受保护内容或清理失败时保留目录并记录失败
* 所有作业共用一个调度器，作业较多时显著减少线程占用
* 复制任务状态查询遇到网络抖动等临时错误时自动重试，连续失败多次才判定失败
* 中止作业时会等待进行中的复制完成取消并完整记录结果，避免结果丢失或与下一次执行重叠
* 为任务记录增加数据库索引，任务历史较多时作业列表与任务查询更快；旧版本数据库升级时自动创建
* 登录安全增强：密码改用 PBKDF2 加盐存储（旧密码登录成功后自动升级），登录 Cookie 不再包含密码摘要并设置 HttpOnly，密码错误次数按来源 IP 分别限制，避免他人输错导致管理员被锁定。**升级后需要重新登录一次；登录过新版本后不支持降级回旧版本**
* 编辑存储目录时，若修改了主机、端口、用户名或阿里云授权地址，需重新输入密码或重新授权，不再沿用已保存的凭据
* 全同步新增空源保护：来源目录为空而目标目录仍有内容时（常见于硬盘或 NAS 掉线后只剩空挂载点），本次跳过同步并记为失败，不再清空目标。**如确实需要清空目标，请手动处理**
* 来源目录无法访问、触发空源保护或所有目标目录都无法访问时，任务记为“失败”并附带原因，不再显示为“完成（部分失败）”
* 目标目录不存在时自动创建；目录不存在时的错误提示会给出具体路径
* 正在执行的作业不允许编辑，需等待执行结束或先中止，避免编辑时静默中止当前任务
* 构建优化：锁定 Python 依赖版本，增加依赖 wheel 缓存与 Android 构建缓存，拉取镜像失败自动重试

## 🐞 修复

* 修复登录有效期未按配置 `expires` 校验，浏览器仍保留 Cookie 时回退为 31 天有效期的问题 [#238](https://github.com/dr34m-cn/taosync/pull/238)
* 修复源目录/目标目录扫描间隔设置不生效，请求仍会密集发送的问题
* 修复任务超时配置 `task_timeout` 不生效的问题；现在任务运行超过设定时长（默认 72 小时，0 表示不限制）会按超时中止。首次全量同步数据量很大时，请按需调大该值
* 修复任务详情中目录创建、删除等记录的时间显示为程序启动时间的问题
* 修复全同步时，源文件仅修改了文件名大小写（如 `Photo.JPG` 改为 `photo.jpg`），在 Windows、SMB、macOS 等不区分大小写的目标上可能把刚复制的文件删除的问题
* 修复全同步时目标端存在与源端同名但类型不同（文件与目录）的项，需要执行两次才能同步完成的问题
* 修复作业执行中被删除时遗留任务记录并报错的问题；启动时会自动清理旧版本遗留的无主记录
* 修复查看正在执行的任务详情时偶发报错的问题
* 修复数据库并发访问偶发冲突的问题
* 修复 StaticX ARM64、ARM32 构建失败的问题
