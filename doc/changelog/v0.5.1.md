## 🚀 特性

* Docker 和可执行文件部署可在「系统设置 → 程序更新」查看当前架构，从 GitHub Releases 下载并拖入可执行文件、ZIP 或 tar.gz 发布包。更新时按程序文件的 SHA-256 核对官方授信清单：未收录的文件会被拒绝，已收录但架构不符的会提示当前架构和更新包架构；两个授信来源均不可用时不会安装
  * 同步运行时禁止更新。更新成功后自动重启并刷新页面；新程序启动失败会回退到上一版本。**从 v0.5.0 首次升级仍需使用原安装方式。** Docker 重启容器会保留更新，重建容器则使用镜像中的版本
  * 授信服务和 GitHub Pages 均使用项目图标，提供中英文清单，可按架构筛选、分页查看版本、发布时间和 SHA-256，并保留同版本历次构建记录。默认「仅正式版」隐藏版本号含 `build`、`dev` 或 `test` 的记录（不区分大小写）；切换「展示全部版本」可查看这些构建。筛选不影响更新校验
* 内置 TaoSync 引擎新增加密目录，可将现有存储的根目录或子目录用作加密备份目标。写入时加密文件内容和文件名，目录名可选加密；通过加密目录浏览或读取时显示原名、原始大小并自动解密。已有明文文件不会自动加密 [#123](https://github.com/dr34m-cn/taosync/issues/123)
  * 保存后锁定密钥和底层目录，防止同步回同一位置；密文校验失败时保留目标端原文件。**请单独备份密钥：若密钥和 TaoSync 数据库同时丢失，加密文件将无法恢复**
* 新增作业关联：一个作业完成或全部成功后，可立即或延迟执行一个或多个后续作业。自动跳过正在运行的目标，禁止循环关联，调度结果可在日志中查看 [#150](https://github.com/dr34m-cn/taosync/issues/150)
* 新增默认关闭的管理员 API 密钥。外部服务可通过 HTTP 请求立即执行指定作业，命令行可按设置页的 `curl` 示例调用；作业列表可查看作业 ID。密钥仅在生成时显示，重置或禁用后旧密钥立即失效 [#214](https://github.com/dr34m-cn/taosync/issues/214) [#211](https://github.com/dr34m-cn/taosync/issues/211) [#200](https://github.com/dr34m-cn/taosync/issues/200)
* 新增 HTTPS 访问（端口 `8025`），保留原 HTTP 入口，两者独立登录。可在设置中上传或粘贴 PEM 证书链和私钥，无需重启即可换证；关闭 HTTPS 后保留证书供再次启用，也可手动清空 [#88](https://github.com/dr34m-cn/taosync/issues/88)
* 任务详情支持单独重试失败文件的复制、移动或删除，无需重跑整个作业。可查看重试进度、结果和失败原因，并保留原始失败记录 [#197](https://github.com/dr34m-cn/taosync/issues/197) [#156](https://github.com/dr34m-cn/taosync/issues/156)
* 桌面和手机的作业列表均显示上次成功复制或移动的文件数与总大小，有失败时另列失败操作数和已知大小。任务历史显示每次执行的起止时间、耗时，以及复制、移动、删除和失败的数量与大小 [#212](https://github.com/dr34m-cn/taosync/issues/212)
* 阿里云盘任务详情可筛选实际秒传成功的文件，任务历史单列秒传数量和大小，不重复计入成功总数
* 所有通知渠道均可开启「仅失败通知」，也可添加备注以区分同类型的多个接收方 [#154](https://github.com/dr34m-cn/taosync/issues/154) [#142](https://github.com/dr34m-cn/taosync/issues/142)
* 配置作业时，可在源目录和目标目录选择器中直接创建并选中子目录（引擎根目录除外）。如需在目标端保留源目录名，可在此新建同名目录；不再提供「保留源目录名」选项，已保存的目标路径不变 [#203](https://github.com/dr34m-cn/taosync/issues/203) [#196](https://github.com/dr34m-cn/taosync/issues/196)

## 🎨 优化

* 已启用但未运行的作业可直接编辑，无需先停用；保存失败会保留原定时规则及下次执行时间 [#227](https://github.com/dr34m-cn/taosync/issues/227)
* 阿里云盘开启秒传后，尝试秒传的门槛从「100 MiB 及以上」降为「大于 10 MiB」。平均传输速度不再计入秒传文件的大小，完成进度仍包含这些文件
* 桌面任务表可横向滚动并固定操作列，作业和任务详情减少底部留白；系统设置适配窄屏和深色主题。新增界面、操作提示和内置重试原因支持简体中文及英文，外部服务的错误信息保留原文
* 主版本号含 `dev-test` 时，Docker 镜像和 Linux StaticX 包均只构建 `amd64`；其他版本保留原有的多架构构建

## 🐞 修复

* 修复内置引擎通过本地目录可能读写 TaoSync 程序或数据库文件的问题。目录选择器和已有挂载均禁止访问程序目录、数据目录及其子目录；即使挂载上级目录，也不能通过相对路径或文件系统链接读取、覆盖或删除受保护内容
* 修复 OpenList/AList 大目录未读完全部分页，导致漏同步、反复复制或目录选择器漏项的问题；分页异常时停止扫描，避免按不完整的结果同步 [#219](https://github.com/dr34m-cn/taosync/issues/219)
* 修复本地、SMB、FTP 和 SFTP 同步时，原文件名未超限却因临时文件名过长而传输失败的问题；目标文件保留原名 [#237](https://github.com/dr34m-cn/taosync/issues/237)
* 修复普通自定义通知和 Server 酱将 HTTP 200 以外的成功状态码误判为发送失败的问题
* 修复顶部状态栏遮挡页面滚动条的问题
