## 🚀 特性

* 系统设置新增程序更新，显示处理器架构和对应的发布平台。Docker 和直接运行可执行文件的部署可在此更新 TaoSync，校验通过后自动重启
  * 页面提供 GitHub Releases 下载入口。请勿上传来历不明的程序；从发布包解压后，可点击或拖入可执行文件，重新选择会替换旧文件，确认后才上传
  * 匹配部署时指定的 `TAO_UPDATE_SHA256` 可直接离线放行；否则并发查询授信服务和 GitHub Pages，按首份有效清单校验当前平台的开发版、预发布版或正式版。授信列表可按页查看版本、架构及 SHA-256
  * 有同步任务运行时不会更新。新程序启动成功后，设置页自动刷新并载入新版前端；启动失败时自动回退到上一个可用版本
  * **从旧版本首次升级到 v0.5.1 仍需使用原安装方式。** Docker 在当前容器重启后保留上传的版本，重建容器时则使用所选镜像的版本
* 桌面端和移动端的作业列表在“上一次执行”中显示成功复制或移动的文件数和总大小；仅在有失败时显示失败操作数及涉及文件的已知总大小
* 任务历史可查看每次执行的开始时间、结束时间和耗时；耗时按天、小时、分钟和秒显示，省略为零的单位。每次执行分别列出复制、移动、删除及失败涉及的文件数和总大小
* 桌面端和移动端任务详情会标记阿里云盘实际秒传成功的文件，支持“仅看秒传”筛选。任务历史仅在有秒传时列出秒传文件数和总大小，不重复计入成功总数

## 🎨 优化

* 阿里云盘开启秒传后，尝试秒传的文件范围由「100 MiB 及以上」扩大到「大于 10 MiB」；10 MiB 及以下直接上传。平均速度不再计入秒传文件的大小，已完成大小和总进度仍包含秒传文件
* 系统设置将同步配置与程序更新分区展示；同步参数和阿里云盘授权服务地址可在同一面板保存，配置项名称可展开查看，布局适配窄屏和深色主题
* 作业列表将上一次执行的状态与执行时间放在同一行。桌面端任务列表加宽统计列和进度列，四种进度状态同排显示；窗口较窄时可横向滚动，操作列固定在右侧
* 目标目录选择器移除“保留源目录名”选项，文件直接同步到所选目标目录；已保存作业的目标路径不变

## 🐞 修复

* 修复顶部状态栏遮挡页面滚动条的问题，滚动页面时状态栏仍固定在顶部
* 修复本地、SMB、FTP 和 SFTP 同步时，原文件名未超限却因临时文件名过长而传输失败的问题，目标文件保留原名
* 修复 OpenList/AList 大目录未完整读取所有分页，导致文件漏同步、重复复制或目录选择器漏项的问题；分页数据异常时停止扫描，避免根据不完整的目录内容执行同步
