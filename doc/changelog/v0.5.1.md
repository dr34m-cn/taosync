## 🚀 特性

### 页面内更新程序

Docker 和可执行文件部署可在「系统设置 → 程序更新」查看当前架构。从 GitHub Releases 下载对应的可执行文件、ZIP 或 tar.gz 发布包，拖入页面即可更新。TaoSync 按程序文件的 SHA-256 核对官方授信清单。文件未收录或两个授信来源均不可用时会停止安装，架构不符时会显示当前架构和更新包架构。

**从 v0.5.0 首次升级仍需使用原安装方式。** 同步期间无法更新。更新成功后程序自动重启并刷新页面，新程序启动失败会回退到上一版本。Docker 重启容器会保留更新，重建容器则使用镜像中的版本。

授信服务和 GitHub Pages 均使用项目图标，提供中英文清单。可按架构筛选，分页查看版本、发布时间、SHA-256 和同版本的历次构建。默认「仅正式版」隐藏版本号含 `build`、`dev` 或 `test` 的记录（不区分大小写）。切换「展示全部版本」可查看这些构建，页面筛选不影响更新校验。

### 加密目录备份

内置 TaoSync 引擎可将现有存储的根目录或子目录用作加密备份目标。写入时加密文件内容和文件名，目录名可选加密。通过加密目录浏览时可见原名和原始大小，读取时自动解密。已有明文文件不会自动加密。

保存后锁定密钥和底层目录，防止同步回同一位置。密文校验失败时保留目标端原文件。**请单独备份密钥。若密钥和 TaoSync 数据库同时丢失，加密文件将无法恢复。** [#123](https://github.com/dr34m-cn/taosync/issues/123)

### 作业联动执行

可选择在一个作业完成或全部成功后，立即或延迟执行一个或多个后续作业。系统会跳过正在运行的目标作业，并阻止循环关联。调度结果可在日志中查看。[#150](https://github.com/dr34m-cn/taosync/issues/150)

### API 密钥分权

通用密钥具有管理员权限，执行作业专用密钥仅可立即执行指定作业或全部作业。两种密钥默认关闭，仅在生成时显示，重置或禁用后对应的旧密钥立即失效。作业列表可查看作业 ID，设置页提供 `curl` 调用示例。[#214](https://github.com/dr34m-cn/taosync/issues/214) [#211](https://github.com/dr34m-cn/taosync/issues/211) [#200](https://github.com/dr34m-cn/taosync/issues/200)

### 启用 HTTPS 访问

可在设置中启用 HTTPS，与原 HTTP 入口独立登录。HTTPS 端口默认 `8025`，可自定义，但不能使用 `8024` 或当前 HTTP 端口。切换端口失败时原地址仍可访问。

上传或粘贴 PEM 证书链和私钥即可换证，无需重启。关闭 HTTPS 后会保留证书供下次启用，也可手动清空。[#88](https://github.com/dr34m-cn/taosync/issues/88)

### 单项与批量重试

任务详情支持单独重试复制、移动或删除失败的文件。在任务详情或任务历史展开的统计中，点击「重试所有失败项」可一次重试该任务各页的失败项。连续选择的文件会加入同一作业正在进行的重试任务。

重试时跳过目录树扫描，逐项显示进度、结果和失败原因，并保留原始失败记录。重试结束后不发送通知，也不触发关联作业。[#197](https://github.com/dr34m-cn/taosync/issues/197) [#156](https://github.com/dr34m-cn/taosync/issues/156)

### 查看同步统计

桌面和手机的作业列表均显示上次成功复制或移动的文件数与总大小，有失败时另列失败操作数和已知大小。任务历史显示每次执行的起止时间、耗时，以及复制、移动、删除和失败的数量与大小。[#212](https://github.com/dr34m-cn/taosync/issues/212)

### 筛选秒传文件

阿里云盘任务详情可筛选秒传成功的文件。任务历史单列秒传数量和大小，成功总数不会重复计算这些文件。

### 失败通知与备注

所有通知渠道均可开启「仅失败通知」。为接收方添加备注后，通知列表以备注为标题，并在下方显示渠道名称，方便区分同一渠道的多个接收方。[#154](https://github.com/dr34m-cn/taosync/issues/154) [#142](https://github.com/dr34m-cn/taosync/issues/142)

### 选目录时直接新建

配置作业时，可在源目录和目标目录选择器中直接创建并选中子目录，引擎根目录除外。原「保留源目录名」选项已移除。如需保留源目录名，可在目标端新建同名目录。已保存的目标路径不变。[#203](https://github.com/dr34m-cn/taosync/issues/203) [#196](https://github.com/dr34m-cn/taosync/issues/196)

## 🎨 优化

### 已启用作业可编辑

作业空闲时可直接编辑，无需先停用。保存失败时会保留原定时规则和下次执行时间。[#227](https://github.com/dr34m-cn/taosync/issues/227)

### 降低秒传门槛

阿里云盘开启秒传后，尝试秒传的门槛从「100 MiB 及以上」降为「大于 10 MiB」。秒传文件计入完成进度，计算平均传输速度时会扣除这部分大小。

### 改善布局与翻译

桌面任务表支持横向滚动，操作列保持固定。作业和任务详情减少底部留白，系统设置适配窄屏和深色主题。新增界面、操作提示和内置重试原因均提供简体中文和英文，外部服务的错误信息保留原文。

## 🐞 修复

### 保护程序和数据目录

内置引擎的本地目录选择器和已有挂载均禁止访问 TaoSync 程序目录、数据目录及其子目录。即使挂载上级目录，也无法通过相对路径或文件系统链接读取、覆盖或删除受保护内容。

### 修复大目录漏项

OpenList/AList 现在会读取大目录的全部分页，避免漏同步、反复复制或目录选择器漏项。遇到分页异常会停止扫描，避免按不完整的结果同步。[#219](https://github.com/dr34m-cn/taosync/issues/219)

### 修复长文件名传输失败

本地、SMB、FTP 和 SFTP 同步时，长度合规的文件名不会再因临时文件名过长而传输失败。目标文件保留原名。[#237](https://github.com/dr34m-cn/taosync/issues/237)

### 修正通知成功判定

普通自定义通知和 Server 酱能正确识别 HTTP 200 以外的成功状态码，避免将已发送的通知误报为失败。

### 修正滚动条与标签显示

顶部状态栏不再遮挡页面滚动条。桌面作业列表中的英文启用和禁用状态标签保持单行显示。

## 🚀 Features

### Update from System Settings

For Docker and standalone installations, open **System Settings → Program update** to check your architecture. Download the matching executable, ZIP, or tar.gz archive from GitHub Releases and drop it onto the page. TaoSync checks the executable’s SHA-256 against the official trusted build registry. Installation stops if the file is unlisted or both registry sources are unavailable. If the architectures differ, TaoSync shows the architecture of both the running program and the update package.

**To upgrade from v0.5.0 for the first time, use your original installation method.** Updates are unavailable during synchronization. After a successful update, TaoSync restarts and reloads the page. If the new program fails to start, TaoSync restores the previous version. Restarting a Docker container keeps the update. Recreating the container uses the version in its image.

The registry service and its GitHub Pages site use the project icon and offer listings in Chinese and English. You can filter by architecture and browse versions, publication times, SHA-256 hashes, and earlier builds of the same version. The default filter hides versions containing `build`, `dev`, or `test`, regardless of case. Select the option to show all versions to see those entries. The filter only affects the listing and has no effect on update verification.

### Back up to encrypted directories

The built-in TaoSync engine can use the root or a subdirectory of existing storage as an encrypted backup destination. It encrypts file contents and filenames on write. Directory name encryption is optional. Browsing the encrypted directory shows original names and sizes, and reading a file decrypts it automatically. Existing plaintext files stay as they are.

Saving the directory locks its key and underlying path to prevent syncing back to the same location. If ciphertext verification fails, TaoSync preserves the original destination file. **Back up the key separately. If you lose both the key and the TaoSync database, you cannot recover the encrypted files.** [#123](https://github.com/dr34m-cn/taosync/issues/123)

### Run linked jobs

A job can trigger one or more follow-up jobs immediately or after a delay. Choose whether to trigger them whenever the job finishes or only when everything succeeds. TaoSync skips jobs already running, prevents circular links, and records scheduling results in the log. [#150](https://github.com/dr34m-cn/taosync/issues/150)

### Choose API key permissions

A general API key grants administrator access. A job execution key can only start a specified job or all jobs immediately. Both keys are disabled by default. Each key is shown only when generated, and resetting or disabling it invalidates the old key immediately. Job IDs appear in the job list, and the settings page includes a `curl` example. [#214](https://github.com/dr34m-cn/taosync/issues/214) [#211](https://github.com/dr34m-cn/taosync/issues/211) [#200](https://github.com/dr34m-cn/taosync/issues/200)

### Enable HTTPS access

Enable HTTPS in settings and sign in separately on the HTTP and HTTPS endpoints. The default HTTPS port is `8025`. You can choose another port except `8024` or the current HTTP port. If a port change fails, the previous HTTPS address stays available.

Upload or paste a PEM certificate chain and private key to replace the certificate without restarting. Disabling HTTPS keeps the certificate for reuse. You can also clear it manually. [#88](https://github.com/dr34m-cn/taosync/issues/88)

### Retry one or all failed items

Retry an individual failed copy, move, or deletion from task details. To retry failures across all pages of a task, select **Retry all failed items** in task details or expand the statistics in task history. Further selections join the retry already running for that job.

Retries skip the directory tree scan. Each item shows its progress, result, and reason for failure alongside the original failure record. Completing a retry does not send notifications or trigger linked jobs. [#197](https://github.com/dr34m-cn/taosync/issues/197) [#156](https://github.com/dr34m-cn/taosync/issues/156)

### View sync statistics

On desktop and mobile, the job list shows the file count and total size successfully copied or moved in the last run. Failed operations appear separately with their count and known size. Task history shows start time, end time, duration, and counts and sizes for copies, moves, deletions, and failures. [#212](https://github.com/dr34m-cn/taosync/issues/212)

### Filter successful rapid uploads

Aliyun Drive task details can show just the files that completed via rapid upload. Task history lists their count and size separately without counting them twice in the success totals.

### Customize failure notifications

Every notification channel supports **Notify only on failure**. Add a note to a recipient to use it as the title in the notification list. The channel name appears underneath so you can distinguish multiple recipients on the same channel. [#154](https://github.com/dr34m-cn/taosync/issues/154) [#142](https://github.com/dr34m-cn/taosync/issues/142)

### Create directories in the picker

When configuring a job, create and select a subdirectory directly in the source or destination picker, except at the engine root. To preserve the source directory name, create a directory with that name at the destination. This replaces the previous option to keep the source directory name. Existing destination paths stay the same. [#203](https://github.com/dr34m-cn/taosync/issues/203) [#196](https://github.com/dr34m-cn/taosync/issues/196)

## 🎨 Improvements

### Edit enabled jobs

Edit an idle job without disabling it first. If saving fails, TaoSync keeps the previous schedule and next run time. [#227](https://github.com/dr34m-cn/taosync/issues/227)

### Lower rapid upload threshold

With rapid upload enabled, Aliyun Drive now attempts it for files larger than 10 MiB. The previous threshold was 100 MiB or larger. Files transferred this way count toward completion, and their size is excluded when calculating average transfer speed.

### Improve layouts and translations

The desktop task table scrolls horizontally while the actions column stays in view. Job and task details have less empty space at the bottom, and System Settings adapts to narrow screens and dark mode. New screens, action messages, and built-in retry reasons are available in Simplified Chinese and English. Errors from external services keep their original wording.

## 🐞 Fixes

### Protect program and data directories

The built-in engine blocks access to TaoSync’s program and data directories and their contents, both in the local directory picker and through existing mounts. Mounting a parent directory does not allow protected content to be read, overwritten, or deleted through relative paths or filesystem links.

### Read every page of large directories

TaoSync reads all pages of large OpenList/AList directories. This fixes missed files, repeated copies, and missing entries in the directory picker. If pagination fails, TaoSync stops the scan before syncing from an incomplete listing. [#219](https://github.com/dr34m-cn/taosync/issues/219)

### Transfer files with long names

Local, SMB, FTP, and SFTP transfers now handle valid filenames even when the temporary name would previously have exceeded the length limit. The destination file keeps its original name. [#237](https://github.com/dr34m-cn/taosync/issues/237)

### Recognize successful notification responses

Basic custom notifications and ServerChan now recognize successful HTTP status codes beyond 200, so delivered notifications are no longer reported as failures.

### Fix scrollbar and status label display

The top status bar no longer covers the page scrollbar. The English Enabled and Disabled labels fit on one line in the desktop job list.
